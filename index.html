Vmware Course Curriculum

  • Fundamentals of server, storage, and network virtualization
  • Type-1 vs Type-2 hypervisors & VMware SDDC ecosystem overview
  • Licensing models, hardware compatibility lists (HCL), and lab planning
  • ESXi host kernel architecture and VMkernel interfaces
  • vCenter Server Appliance (VCSA) components & Single Sign-On
  • Data centers, clusters, resource pools, and vSphere Client navigation
  • ESXi interactive & scripted installation and DCUI setup
  • Deploying and configuring vCenter Server Appliance (Stage 1 & Stage 2)
  • Configuring NTP, DNS, syslog forwarding, and host profiles
  • Creating VMs, installing VMware Tools, and hardware version upgrades
  • Templates, cloning, OVF/OVA deployment, and Content Libraries
  • Snapshot lifecycle management and vMotion live migrations
  • vSphere Standard Switches (vSS) vs Distributed Switches (vDS)
  • Port groups, VLAN tagging (EST, VST, VGT), and NIC teaming
  • Traffic shaping, Network I/O Control (NIOC), and LACP
  • VMFS, NFS, iSCSI, and Fibre Channel SAN datastore configuration
  • Storage vMotion, thin vs thick provisioning, and Storage DRS
  • Hybrid cloud storage integration with Azure Storage & Blob tiers
  • vSphere High Availability (HA) admission control and datastore heartbeating
  • vSphere Fault Tolerance (FT) for zero-downtime mission-critical workloads
  • Proactive HA and host failure isolation response policies
  • Distributed Resource Scheduler (DRS) automation levels & affinity rules
  • CPU and memory shares, reservations, limits, and resource pools
  • Enhanced vMotion Compatibility (EVC) across mixed CPU generations
  • Role-Based Access Control (RBAC), Active Directory integration, and SSO
  • ESXi Lockdown Mode, firewall hardening, and TPM/Secure Boot
  • VM encryption, vMotion encryption, and KMS key management
  • vCenter Server file-based backup and restore strategies
  • vSphere Replication and Site Recovery Manager (SRM) workflows
  • RPO/RTO planning, failover testing, and enterprise backup tools
  • Automating VMware administration with PowerCLI and PowerShell
  • Infrastructure as Code provisioning using Terraform vSphere Provider
  • REST APIs and vSphere Lifecycle Manager (vLCM) automated patching
  • Using esxtop, vSphere performance charts, and alarm definitions
  • Diagnosing CPU ready time, memory ballooning, and storage latency
  • Capacity planning and bottleneck resolution in production clusters
  • Design and deploy a production-grade multi-host HA/DRS vSphere cluster
  • Configure distributed networking, shared storage, RBAC, and automated backups
  • Present architecture documentation and live failover demo to mentors
